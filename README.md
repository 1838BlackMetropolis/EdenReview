# Historic Eden Cemetery — Project Walk-Through

Branded HTML slide deck used to walk Eden Cemetery through the 1838 Black Metropolis deliverable:
Brand Narrative & Awareness Strategy, Tour, and Technical Architecture.

## Run it
Open `index.html` in a browser, or serve the repo with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Navigate
- `→` / `←` / space: next / previous slide
- `F`: fullscreen · `O`: overview grid · `Home` / `End`
- Click the right half of a slide to advance, the left half to go back
- Deep-link to a slide with `#12`

## Edit
Everything lives in `index.html`. Each `<section class="slide">` is one slide; the `data-sec` attribute sets the footer label.
Tour theme titles on slide 18 are placeholders — replace the `[Theme title]` cards.
